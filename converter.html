DOCX is converted to clean HTML first. Complex layouts, fonts, headers and page breaks may change.

Cell values and basic formatting are exported. Charts, macros and print-area rules may not be preserved.

Experimental text-first conversion. It extracts slide text but does not reproduce original positions, diagrams, animations or embedded media.

Selection order mattersPDFs are merged in the order shown in the file list.

Encrypted or password-protected PDFs cannot be processed without their password.

Lossy compression rasterizes pages. Searchable text, links, forms and selectable text are removed.

A safety limit of 200 files and 100 MB uncompressed data is applied.

Exports readable spine content from DRM-free EPUB files. Complex styling and fixed-layout pages are simplified.

Each TXT, HTML or Markdown file becomes a chapter in one DRM-free EPUB.

Nested arrays are stored as JSON text inside a cell.

Supports JSON, XML, YAML and YML. Attributes use an @ prefix when XML becomes structured data.

The OCR engine and selected language data are downloaded when first used. Printed text works best.

Creates a searchable rasterized PDF. Original links, forms, annotations and vector text are not preserved.

Supports common MIME, Base64 and quoted-printable messages. Signed, encrypted or unusually nested email may be simplified.

OTF can be read and converted to TTF-based outputs. WOFF2 is not included because it needs an additional WASM codec.

Converts geometry from OBJ, STL or PLY. OBJ material files, textures, rigs and animations are not imported.

Generates an Express/OpenAPI starter. It does not deploy a live API or include production conversion engines.

Generates schema, RBAC guidance and integration notes. Authentication, billing and data protection must be completed on a secure backend.
