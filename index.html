Frequently asked questions

File conversion, privacy and counters

Are files uploaded to PixelSwitch?

Supported tools process files in browser memory. The static website does not intentionally send selected file contents to a conversion server.

What does the live conversion counter measure?

It counts output files only after a conversion finishes successfully. It does not record filenames or file contents.

Can the counters show site-wide totals?

Yes. Deploy the included API and set the activity API URL in the site configuration. Without that setting, totals remain private to the current browser.

Which file types can I convert?

PixelSwitch includes tools for common image, PDF, Office, ZIP, EPUB, structured-data, subtitle, email, font and 3D model formats. Exact support is listed on each category page.
