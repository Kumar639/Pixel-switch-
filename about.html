About PixelSwitch

Simple tools with honest limitations.

PixelSwitch organizes practical file conversion tools into clear categories and processes files locally whenever browser technology makes that reliable.

Our purpose

Make file conversion easier to understand.

Many converter websites mix unrelated formats, hide limits and require uploads before explaining what will happen. PixelSwitch uses focused pages, readable settings and clear notices so people can choose the right tool before selecting a file.

The website includes lightweight browser tools and experimental advanced converters. Exact Office, font, OCR and 3D results can vary because formats do not share the same features.

01

Useful first

Every tool should solve a clear file problem.

02

Private by default

Browser processing is preferred when practical.

03

Honest results

Lossy or experimental conversions are labelled.

Privacy

What happens to your files?

Selected files are processed inside your browser for the included static tools. Supporting JavaScript libraries can load from public CDNs, but selected file bytes are not intentionally sent to those library providers.

01

No conversion account

You can use the converter without creating an account.

02

Temporary browser memory

Generated download URLs are revoked when files are cleared or the page closes.

03

Comments are separate

Community comments contain only the name and message a visitor submits. Uploaded conversion files are never attached to comments.

Questions

Frequently asked questions

Are my files uploaded?

The included converter tools process files in the browser. A future hosted backend may be needed for larger or unsupported conversions, and that would require a separate privacy notice.

Why can formatting change?

Word, spreadsheet, presentation, OCR, font and 3D formats contain features that may not have direct equivalents in the output format.

Are community comments public?

With the included local fallback, comments are visible only in the same browser. Connect the included comments API to make comments shared between visitors.

Can I use the generated API starter in production?

It is a starting scaffold only. Production use still requires authentication, storage, queues, monitoring, security review and conversion workers.
